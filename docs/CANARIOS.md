# Canarios — backend-MAN.OGG

Registro de canarios de este repo. La política completa vive en el contexto del director; aquí solo lo que el repo necesita.

## Fórmula
- Apertura: `Zapatito roto.`
- Cierre: `Zapatito roto · <ROL> · <palabra>`
- La palabra de un ticket se asigna al despachar y nunca se repite en el proyecto.
- Informe sin canario o con otra palabra: se rechaza y se relanza con contexto fresco.

## Familia de este repo
rocas sedimentarias. Libres: caliza, arenisca, lutita, travertino, conglomerado, brecha, dolomita, marga, sílex.
