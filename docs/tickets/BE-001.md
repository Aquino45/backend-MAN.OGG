## Requisitos técnicos
1. **Dependencias:** Python 3.12, Django 5.2 LTS, Django REST Framework, django-environ, django-cors-headers y psycopg 3 (binary). Para desarrollo: pytest, pytest-django y ruff. Versiones **exactas** (`==`), comprobadas en PyPI (`pip index versions <paquete>`); nunca de memoria.
2. **Dockerfile:**
   - base `python:3.12-slim`;
   - instala lo que pide GeoDjango (`binutils libproj-dev gdal-bin`, con `--no-install-recommends`);
   - `PYTHONDONTWRITEBYTECODE=1` y `PYTHONUNBUFFERED=1`;
   - corre con un usuario sin privilegios.
3. **docker-compose.yml:**
   - **Servicio `db`** (`postgis/postgis:16-3.4`): healthcheck con `pg_isready`, volumen con nombre, `./db/init` montado en `/docker-entrypoint-initdb.d:ro` y `TZ` del entorno.
   - **Servicio `api`:** `build: .`, `depends_on` con `db: condition: service_healthy`, el código montado para desarrollo y `runserver 0.0.0.0` en el puerto del entorno.
   - **Sin `container_name`**: así dos worktrees pueden convivir. El nombre del proyecto sale de `COMPOSE_PROJECT_NAME` en `.env`. Todos los puertos salen del `.env`.
4. **`.env.example`**, documentado línea por línea. La contraseña vive en un solo lugar (nada de `DATABASE_URL` que la repita):
   `COMPOSE_PROJECT_NAME=manogg`, `POSTGRES_DB=censo_arboreo`, `POSTGRES_USER=ambiental`, `POSTGRES_PASSWORD=cambia_esta_clave`, `DB_HOST=db`, `DB_PUERTO=5432`, `DB_PUERTO_HOST=5432`, `DB_ESQUEMA=censo`, `DJANGO_SECRET_KEY=cambia_esta_clave_larga`, `DJANGO_DEBUG=true`, `DJANGO_ALLOWED_HOSTS=localhost,127.0.0.1`, `CORS_ORIGENES_PERMITIDOS=http://localhost:5173`, `API_PUERTO=8000`, `TZ=America/Lima`.
5. **`config/settings.py`:**
   - todo sale de `environ`;
   - motor `django.contrib.gis.db.backends.postgis`, con `search_path` `<DB_ESQUEMA>,public`;
   - apps: `django.contrib.gis`, `rest_framework`, `corsheaders` y `apps.core`;
   - `LANGUAGE_CODE="es-pe"`, `TIME_ZONE` desde el entorno y `USE_TZ=True`;
   - si falta una variable obligatoria, falla con un mensaje claro (nada de valores por defecto escondidos para los secretos).
6. **`config/constantes.py`** (constantes de negocio, en MAYÚSCULAS y con docstring):
   - `PREFIJO_API = "api/v1/"`;
   - `SRID_UTM_CENSO = 32718` (UTM 18S, como vienen los datos de la brigada);
   - `SRID_MAPA = 4326`.

   `config/urls.py` usa `PREFIJO_API`; no lo repite escrito a mano.
